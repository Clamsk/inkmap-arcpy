水墨地图开源｜墨纹素材也分享

## 正文（可直接复制）

终于把这套水墨区位图，整理成了可以复用的素材、Python 包和 AI 制图 Skill。🗺️

① 墨纹与纸纹，分开保存
上面放透明白墨纹，下面垫颜色，再用独立纸纹托底。白墨 RGB 始终是白色，浓淡写在透明度里：浓墨处白色覆盖少，底色更深；淡墨处覆盖多，颜色更浅。
同一张墨纹，换底色就能得到青蓝、松绿或淡赭，不用为每种颜色重新做素材。

② 底稿怎样做
使用 Washes 湿媒体引擎，按“淡墨铺底 → 半干时局部回流 → 干燥 → 再叠不同浓度墨层”做三遍洗染。保存每遍沉积与最终叠加场，再提取透明白素材；纸面高度单独提取纸纹。
选定底稿保留柔和浓淡过渡，未追加咖啡环和细颗粒。

③ 整张地图统一表达
主路保留纸白路带，外沿用灰青；支路淡暖灰，步道用更细的连续线。建筑薄墨灰，真实广场与历史建筑少量暖色洗染。站点改为空心灰青圈，地标用暖墨圈和暗朱砂。
图例、宋楷文字、比例尺与指北针也一起整理。

④ 包和 Skill，负责复用
inkmap-arcpy 0.4.0 负责样式、布局与导出；arcpy-watercolor-map Skill 引导 Agent 检查环境、真实数据、投影、图层绑定和成果。
另附福州鼓楼、上海外滩、洛杉矶回声湖的 42 个局部 GeoJSON 图层及导入脚本。三城案例放在最后，装帧根据城市气质调整。

GitHub：Clamsk/inkmap-arcpy
https://github.com/Clamsk/inkmap-arcpy
releases/0.4.0：素材包、wheel、Skill ZIP、三城复用资源包。

制图直接用 PNG，无需运行流体仿真。需要 Windows＋已授权的 ArcGIS Pro 3.x，本机 Pro 3.0 实测。材质原生512×512，湿媒体参数是艺术近似；代码、生成素材与 Skill 为 MIT，OSM 数据按 ODbL 分享并保留署名。社区名称点不代表社区行政边界。
